# ReportMachine Topic Input

Fill this file before running `scripts/run_article.py`.

## Task Type

industry or earnings

## Topic

Describe the company, industry, technology, supply chain, regulation, or market structure to analyze.

## Core Question

What should the article answer?

## Recent Trigger

Add recent news, filing, earnings release, IR deck, conference call, regulation, or market event.

## Required Source Notes

List required URLs or local file names. For earnings work, include current-quarter and prior-quarter materials.

## Output Notes

State whether the expected output is a full report, web article, executive brief, or QA review.
